# Орфографические двойники

Тренажёр задания 14 ЕГЭ по русскому языку: «Союзы» — 62 карточки, «Предлоги» — 111, «Наречия» — 84. Всего 257 карточек. Тематический блок выбирается в компактном выпадающем списке.

## Исходники и запуск

Репозиторий содержит полноценные исходники статического приложения, без сборки и внешних зависимостей:

- `index.html` — разметка интерфейса.
- `styles.css`, `assets/space_valley_bg.png`, `favicon.svg` — оформление.
- `app.js` — выбор раздела, карточки, проверка ответов, объяснения и журнал ошибок.
- `conjunctions-data.js`, `prepositions-data.js`, `adverbs-data.js` — действующие учебные наборы.
- `progress-migration.js` — перенос ранее сохранённого прогресса для наборов с явными правилами миграции.

Для локального запуска из корня репозитория:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173/. Прогресс хранится в localStorage браузера отдельно для каждого раздела и адреса сайта.

## GitHub Pages

Публикация: ветка `main`, корень `/`. Файл `.nojekyll` отключает обработку Jekyll.

Базовый путь сайта — `/ege14-orfograficheskie-dvoiniki/`. Все ресурсы подключены относительными путями. Текущая версия не использует Vite; при будущем переходе на Vite следует задать `base: '/ege14-orfograficheskie-dvoiniki/'`.

## Расширение тренажёра

Наборы регистрируются в `window.EGE14_BLOCKS` до загрузки `app.js`. Для будущих разделов «Сложные слова» и «Частицы» можно добавить отдельные файлы данных с уникальными `id` и `version`, полями `title` и `exercises`, затем подключить их в `index.html`. Список разделов формируется приложением из зарегистрированных наборов. Формат карточки можно посмотреть в действующих файлах данных.

Исследовательские папки, рабочие отчёты, исходные учебные сборники и инструменты их обработки в этот репозиторий не включены.
